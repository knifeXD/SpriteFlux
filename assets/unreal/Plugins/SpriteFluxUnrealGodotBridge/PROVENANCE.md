# Provenance

`SpriteFluxUnrealGodotBridge` is a SpriteFlux-owned implementation using Unreal Engine's public Python and glTF Exporter APIs. It is not a copy or fork of another plugin.

Research source: `https://github.com/judink/unreal-to-godot-exporter`, pinned during evaluation at commit `02cc7811208ba2f3cc91372756d2cbf49664b60b`. That project demonstrated the feasibility of wrapping Unreal's glTF exporter, but the pinned tree did not contain a standalone license file or full license text. No upstream source file is redistributed here.

The bridge behavior was independently specified from UE 5.8 public API behavior and the reusable acceptance contract in `references/standard-humanoid-animation-pipeline.md`.
